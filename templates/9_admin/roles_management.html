System Roles

Admin

System

Full system access with all administrative privileges

Permissions:

  • ✓ Manage all users
  • ✓ Configure system settings
  • ✓ View audit logs
  • ✓ Manage backups
  • ✓ Create/Edit invoices
  • ✓ Access all reports

Manager

Standard

Elevated access to manage operations and staff

Permissions:

  • ✓ Manage staff users
  • ✓ Create/Edit invoices
  • ✓ View reports
  • ✓ Manage clients
  • ✗ System settings
  • ✗ Manage backups

Staff

Standard

Standard access for daily operations

Permissions:

  • ✓ View own profile
  • ✓ Create/View invoices
  • ✓ Manage clients
  • ✓ Process payments
  • ✗ Edit other users
  • ✗ System settings

User

Basic

Basic read-only access for general users

Permissions:

  • ✓ View own profile
  • ✓ View invoices
  • ✓ View clients (read-only)
  • ✓ Access reports
  • ✗ Create/Edit invoices
  • ✗ View financial details
