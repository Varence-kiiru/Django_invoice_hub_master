⏰ Automated Daily Backups

Automated backups are scheduled to run daily at 2:00 AM (database only). To enable automated backups:

  1. Ensure Redis is running
  2. Start Celery worker with: celery -A invoicing_app worker --loglevel=info -c 2
  3. Start Celery Beat with: celery -A invoicing_app beat --loglevel=info

💡 Automated backups keep only the last 30 days (old backups are auto-cleaned weekly).

Before Restoring a Backup

⚠️ Important: Restoring from a backup will overwrite all current database data and optionally restore media files. Please ensure you have:
  • ✓ Created a backup of your current database
  • ✓ Verified the backup file is valid and uncorrupted
  • ✓ Notified all users that the system will be temporarily unavailable
  • ✓ Scheduled the restore during a maintenance window
  • ✓ Tested the backup on a staging environment (recommended)
💡 Tip: If restoring from a .zip backup, all media files (logos, invoices, receipts, etc.) will be automatically restored along with the database.
